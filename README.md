## File Naming

Posts use a numbered Markdown filename so they remain easy to follow in chronological order:

```text
NN_Topic_Name.md
```

For example:

```text
01_Rest_VS_Soap.md
```

## Writing a New Post

1. Create a new Markdown file using the next available number.
2. Add the post to the **Posts** table above.
3. Keep the article focused, clear, and useful as a standalone reference.
4. Publish one post for each day of the series.
